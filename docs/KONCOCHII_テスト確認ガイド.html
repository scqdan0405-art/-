1. これは何か

ホーチミンの観光客が、スマホで予約してコンビニに荷物を預け、QRコードと暗証番号（OTP）で受け取るサービスです。コンビニは棚を置かず、バックヤードの空きスペースだけで運用します。

👤 利用者（旅行者）スマホのWebで予約・決済し、荷物を預けて受け取る。アプリのインストール不要・多言語対応。
🏪 コンビニ店舗操作は「預かる」「返す」の2つだけ。棚・設備投資なし。
📊 運営（KONCOCHII）予約・決済・問い合わせ・精算・保険をまとめて管理。
このガイドは「動くプロトタイプ（試作品）」を確認するためのものです。決済は本物ではなく、データはブラウザを閉じると消えます。仕組みと画面の流れを体験するのが目的です。

4. 利用者フロー（すべてWebで完結）

探す・選ぶGoogle/Maps/Trip.com等から店舗ページへ。預け先を選ぶ。
予約・決済サイズ・個数・時間を選び、事前決済する。
QR・OTP発行予約確定でQRコードと6桁OTPが発行される。
店舗で預けるQRとOTPを提示 → スタッフが確認しタグを付けて保管。
受け取る受け取り用OTPで本人確認して荷物を返却。予約時間内なら何度でも受け取り可。

5. 店舗フロー（かんたん3ステップ）

預かるQR＋OTP確認 → 荷物タグを装着 → バックヤードへ。
保管する返却時間まで安全に保管（棚は不要）。
返す受け取りOTP確認 → 荷物を返却して完了。

8. テスト項目 0 / 0

プロトタイプを開いて、上から順に確認してください。チェックは自動で保存され、次に開いても残ります。

👤 利用者（予約する）

  • 店舗一覧が表示され、空き状況バッジが見える 必須「利用者」タブ。日付を変えると空き状況が変わることも確認。
  • 店舗を選び、サイズ・時間を選ぶと料金が正しく出る 必須例: S×6時間=70,000 VND、L×12時間=200,000 VND。
  • メール・決済方法を選んで予約が確定できる 必須補償への同意にチェックしないと進めないことも確認。
  • 予約後にQRコードと6桁OTPが表示される 必須OTPの数字をメモしておく（次の店舗テストで使う）。
  • 「マイ予約」に今の予約が出る 推奨予約番号（KC-0001など）とOTPが確認できる。

🏪 店舗（預かる・返す）

  • 「店舗」タブで予約番号＋OTPを入力し「預かる」ができる 必須間違ったOTPだとエラーになることも確認。
  • タグ番号を入れて保管を開始できる 必須例: TAG-A01。保管中一覧に荷物が並ぶ。
  • 「返す」で予約番号＋OTPを入力し返却できる 必須返却すると一覧から消える。
  • 保管していない予約は返却できない 推奨まだ預けていない予約番号で「返す」を試すとエラー。

📊 管理（集計を見る）

  • 「管理」タブで予約数・保管中・売上が数えられている 必須予約した分だけ数字が増える。
  • 収益・精算の内訳（店舗40%など）が自動計算される 推奨売上に対して店舗支払い・手数料・保険料が引かれている。
  • 全予約一覧に状態（保管中/返却完了など）が出る 推奨操作に合わせて状態が変わる。

🌐 その他

  • 右上で言語を切り替えると表示が変わる 推奨日本語・英語・ベトナム語などを試す。
  • スマホ幅（画面を狭く）でも崩れず使える 推奨ブラウザ幅を狭めて確認。

9. 確認するときの注意点

  • これは試作品です。決済は本物ではなく、カード番号は何でも通ります（末尾4000は失敗になる設定）。
  • ブラウザを閉じるとデータ（予約）は消えます。続けてテストするときは開いたままにしてください。
  • 本番では、預け入れ用と受け取り用でOTPを分ける・写真必須など、より安全な仕組みになります（本ガイドの試作品では簡略化しています）。
  • 気づいた点・分かりにくい点があればメモして共有してください。改善に反映します。
